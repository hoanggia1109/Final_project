🚀 HƯỚNG DẪN NHANH - CẤU HÌNH GỬI EMAIL
========================================

📋 BƯỚC 1: Cấu hình Gmail App Password
---------------------------------------
1. Vào: https://myaccount.google.com/security
2. Bật "Xác minh 2 bước"
3. Vào: https://myaccount.google.com/apppasswords
4. Tạo App Password → Copy mật khẩu 16 ký tự


📋 BƯỚC 2: Tạo file .env
---------------------------------------
Tạo file .env trong thư mục server_node với nội dung:

EMAIL_USER=natomi1404@gmail.com         
EMAIL_PASSWORD=yild gzmi zabg xofk
FRONTEND_URL=http://localhost:3000


📋 BƯỚC 3: Test email
---------------------------------------
node test-email.js your-test-email@gmail.com "Your Name"

Ví dụ:
node test-email.js test@gmail.com "Nguyễn Văn A"


📋 BƯỚC 4: Restart server
---------------------------------------
npm start


✅ HOÀN TẤT!
---------------------------------------
Giờ khi user đăng ký, họ sẽ nhận được email xác nhận tự động.

📖 Đọc thêm: EMAIL_SETUP.md để biết chi tiết và troubleshooting
